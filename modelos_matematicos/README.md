# Módulo: [Modelos Matemáticos]

Esse diretório contém os scripts responsáveis por realizar previsões gráficas da tuberculose

---

## 1. Dependências e instalação

Antes de executar os arquivos dessa pasta, você precisa instalar as bibliotecas abaixo no seu terminal(com o python já instalado):

`pip install matplotlib numpy scipy`

---

## 2. Intruções

As variáveis que estão comentadas podem ser alteradas para mudar gráfico. O resultado esperado é que as funções se compotem de acordo com as taxas. Exemplo: ao aumentar a taxa de infecção (beta), a função dos infectados deve aumentar seu pico
